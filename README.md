# BLXCKCHAT

Encrypted Chat Interface for JEXXXUS Ecosystem.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Lucide Icons
- **Animation:** Motion (v12+)

## Features
- **Motion UI:** Smooth, fluid transitions.
- **Real-time:** Instant messaging (mocked for now).
- **Secure:** End-to-end encryption (planned).
